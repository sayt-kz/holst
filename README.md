# Холст

Простое онлайн-приложение для рисования в браузере — открыл и рисуешь, без регистрации и установки.

**Открыть:** https://jigiti2013-oss.github.io/holst/

## Возможности

- Кисть с плавными линиями, ластик, заливка, линия, прямоугольник, круг (Shift — ровные фигуры)
- 12 цветов + свой цвет, толщина 1–50 px, прозрачность 10–100%
- Фон: белый, бумага, чёрный
- Отмена/повтор (50 шагов), очистка с подтверждением, сохранение в PNG
- Мышь, палец, стилус (сила нажатия), телефон и планшет, тёмная тема

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| B / E / G | Кисть / Ластик / Заливка |
| L / R / O | Линия / Прямоугольник / Круг |
| `[` / `]` | Размер кисти |
| Ctrl+Z | Отмена |
| Ctrl+Shift+Z, Ctrl+Y | Повтор |
| Ctrl+S | Сохранить PNG |

Весь код — один файл `index.html` (HTML + CSS + JavaScript, Canvas), без сборки и зависимостей.
